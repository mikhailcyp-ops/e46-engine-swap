PNPECU EMU Black M43 BMS46 solution


This page refers to version 4 PNPECU M43 solution only. Make sure to check the adapter tag for your version.

30/7/2024 - Version 4 is latest.

PNPECU has developed the M43 solution to satisfy customer requests to allow the M43 engine to be fully controlled

M43 OEM Sensors Usage


• OEM Lambda sensors are not used
• MAF sensor is not used



• Crank sensor - used as OEM
• Cam sensor - used as OEM
• Coolant temperature - used as OEM
• Air temp sensor - used as OEM
• TPS sensor - used as OEM
• Vehicle Speed Sensor Rear Right - used for vehicle speed
• Knock sensors - used as OEM
• Engine oil pressure switch - used as OEM
• Oil level switch - used as OEM



M43 OEM Actuator Usage


• Secondary air pump - not used
• Secondary air valve - not used



• Ignition coil wiring - used as OEM
• Tachometer signal - used as OEM
• Fuel pump relay - used as OEM
• Idle control valve - used as OEM
• AC Compressor relay - used as OEM
• Econometer output - used as OEM
• DISA Valve - used as OEM


CAN BUS Compatibility


The cars that the M43 BMS46 originally came in did communicate with the rest of the vehicle via CAN BUS.
Use E46 canbus setup in the ecu

Options at ordering
