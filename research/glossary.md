# Glossary

| Term | Meaning |
|------|---------|
| DME | Digital Motor Electronics — BMW engine ECU |
| EWS | Electronic immobilizer — must agree with DME/key |
| LCI | Lifecycle impulse — mid-run facelift |
| VANOS | Variable valve timing (M52/M54/S54 etc.) |
| DBW | Drive-by-wire electronic throttle |
| GS6-37BZ | Common Getrag 6-speed in many E46 six-cylinder cars |
| CAN | Controller Area Network — module communication bus |
| xi | E46 AWD variant |

Add terms as you encounter them in wiring diagrams and swap guides.
