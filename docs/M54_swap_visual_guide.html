M54B30 (X5 E53) → BMW E46 (ex-M43B19)

Донор с АКПП, в машине — МКПП. MS43 + моторная коса X5, кузовная проводка E46. Диаграммы и порядок работ; детали — в M54_X5_to_E46_M43_swap_plan.md.

Siemens MS43 BMS46 → стыковка Manual M54 flash Cyprus / EU
До закупок: колокол КПП 318 M43 часто не совместим с M54; маховик с АКПП-донора не подходит под сцепление. Прошивка MS43 должна быть под Manual, не E53 Auto. Не включать зажигание до решения по EWS.

Последовательность фаз

  1. Инвентаризация

    Фото разъёмов, прозвонка X60004 / X6011 / X5. Таблица «есть / нет»: DBW, clutch, brake 4-wire, SAP, DMTL, вентилятор PWM.

  2. Механика

    Поддон E46 M54, опоры 6-цил., manual flywheel, КПП/колокол, кардан. Снять навесное АКПП с двигателя.

  3. Стыковка X60004 + X6011

    Четыре индикаторные цепи с кузова → X6011 на моторной стороне; стартер/D+; разъём у крыла (3+1).

  4. Педаль, сцепление, тормоз

    DBW manual 786282; X11400→X60004; clutch → pin 23; BLS 4-wire → 24/28.

  5. EWS и прошивка Manual

    Комплект X5 или sync E46; MS43 не под E53 Auto. Адаптации DME после flash.

  6. Pre-start

    Массы, EKP relay logic (pin 10), CAN 36–37, без 12 V на сигналы педали.

  7. Первый пуск

    INPA, лампы приборки, вентилятор, короткая обкатка.
