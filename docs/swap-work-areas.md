# Swap work areas — master checklist

Use this when estimating labor and parts for any swap. Copy sections into your build log and mark status.

## 1. Engine & ancillaries

- [ ] Engine block / head condition documented
- [ ] Oil pan (clearance vs steering / subframe)
- [ ] Pickup tube / baffle (cornering starvation)
- [ ] Water pump, thermostat, hoses, expansion tank
- [ ] Radiator / fan / shroud (S54 and FI often need more cooling)
- [ ] AC compressor, lines, bracket
- [ ] Power steering pump and lines
- [ ] Intake, MAF, throttle body
- [ ] Exhaust manifolds / headers, downpipe, O2 sensors
- [ ] Engine mounts (OEM vs aftermarket)
- [ ] Flywheel, clutch, slave cylinder (manual)

## 2. Transmission & driveline

- [ ] Bellhousing / adapter (non-BMW)
- [ ] Clutch hydraulics bleed
- [ ] Driveshaft length and flange
- [ ] Differential ratio and LSD
- [ ] Guibo / center bearing
- [ ] Shift linkage or shifter conversion

## 3. Fuel system

- [ ] Pump (in-tank), regulator, lines
- [ ] Injectors sized for target power
- [ ] Return vs returnless setup
- [ ] EVAP and charcoal canister (emissions)

## 4. Electrical

- [ ] Engine ECU (DME or standalone)
- [ ] Immobilizer / key sync (EWS)
- [ ] Engine harness (full swap vs merge)
- [ ] Starter, alternator, ground straps
- [ ] Cluster programming / swap
- [ ] ABS/DSC compatibility
- [ ] OBD readiness for inspection

## 5. Cooling & lubrication

- [ ] Radiator capacity
- [ ] Oil cooler (track / high power)
- [ ] Transmission cooler (auto / hard use)
- [ ] Coolant bleed procedure documented

## 6. Chassis & safety

- [ ] Subframe bushings / cracks inspected (common E46 issue)
- [ ] Motor mount limiters
- [ ] Brake upgrade for power increase
- [ ] Tire/wheel fitment
- [ ] Roll bar / track safety if applicable

## 7. Legal & paperwork

- [ ] Registration rules for engine change
- [ ] Emissions test strategy
- [ ] Insurance notified
- [ ] Receipts and photos for audit trail

## 8. Commissioning

- [ ] Base tune / break-in schedule
- [ ] Leak checks (fuel, oil, coolant)
- [ ] Torque specs for critical fasteners logged
- [ ] First-drive checklist (temps, noises, codes)
